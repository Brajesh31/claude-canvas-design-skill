# Canvas Design Skill

A Claude skill for creating original, highly crafted visual artwork as PNG or PDF, guided by a written design philosophy.

## Repository contents

- `SKILL.md`: complete skill instructions.
- `canvas-fonts/`: bundled font files and their accompanying font license notices.

## Use

Place this skill in the skills directory supported by your Claude-compatible environment. Keep the `canvas-fonts/` directory alongside `SKILL.md`, because the instructions refer to these bundled fonts.

The skill guides a two-stage workflow: develop a visual philosophy, then express it as a polished visual artifact.

## Included assets

The original font collection is retained in `canvas-fonts/`, including font binaries and their accompanying OFL notices.
