# Canvas Design

## Purpose
Guide the creation of original visual compositions for posters, covers, editorial graphics, presentations, social assets, and other canvas-based designs. Start with the communication goal, not effects.

## Brief
Identify the audience, message, medium, dimensions, viewing distance, placement, required text, brand constraints, accessibility needs, and delivery format. If details are missing, state reasonable assumptions.

## Design process
1. Reduce the brief to one primary message and a small number of supporting messages.
2. Establish a hierarchy using scale, position, contrast, spacing, and grouping.
3. Choose a grid and alignment system before placing decorative elements.
4. Select a type system with clear roles for headline, subhead, body, labels, and metadata.
5. Use a restrained palette with sufficient contrast. Do not rely on color alone to communicate status.
6. Use imagery only when it strengthens the message. Check crop, focal point, resolution, and usage rights.
7. Build a consistent spacing rhythm and align related elements.
8. Review at actual output size and at thumbnail size.
9. Export for the target medium and verify dimensions, color mode, fonts, and legibility.

## Composition principles
- One dominant focal point is usually stronger than several competing ones.
- Negative space is an active layout element.
- Keep line lengths comfortable and avoid dense text blocks.
- Use contrast intentionally, not everywhere.
- Maintain consistent margins and optical alignment.
- Decorative details must support the concept and may be removed if they do not.

## Accessibility and production
Check text contrast, minimum type size, reading order, and color-independent cues. For print, confirm bleed, safe area, image resolution, and the printer's color requirements. For digital, check responsive crops and export formats.

## Deliverables
Return a concise design rationale, a layout specification, typography and color tokens, asset requirements, and an export checklist. Do not claim to have created an editable source file unless one was actually produced.
